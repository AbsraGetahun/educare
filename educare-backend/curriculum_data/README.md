# Curriculum PDFs

Place all six mathematics textbooks in this folder, then rebuild the search index:

```bash
cd educare-backend
python embed_curriculum.py
```

Expected files:

- `Extreme Mathematics Grade 9&10.pdf`
- `Extreme Mathematics Grade 11&12.pdf`
- `grade9_math.pdf`
- `grade10_math.pdf`
- `grade11_math.pdf`
- `grade12_math.pdf`

After adding PDFs, restart the Flask backend.
